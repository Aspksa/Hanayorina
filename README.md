# Hanayorina

Начальная основа проекта на TypeScript с локальной страницей и поддержкой PostgreSQL.

## Запуск

Установите Node.js 22 или новее и дважды нажмите `Hanayorina.bat`. Откройте http://127.0.0.1:4173. При первом запуске нужен интернет для установки зависимостей.

[Полная инструкция по запуску и настройке PostgreSQL](docs/setup.md)

## Структура

- `src/server/` — локальный сервер.
- `src/database/` — подключение и подготовка PostgreSQL.
- `config/` — настройки TypeScript и пример настроек базы.
- `docs/` — инструкции.

Файлы `package.json`, `package-lock.json` и `Hanayorina.bat` находятся в корне для установки зависимостей и запуска. В настройках доступны ключи модели и проверка соединения с переключением ключа. Чат и сохранение памяти ещё не реализованы.
