# Hanayorina

Начальная основа проекта на TypeScript: локальная страница и запуск в Windows. Дополнительные функции ещё не реализованы.

## Запуск в Windows

1. Установите [Node.js](https://nodejs.org/) версии 22 или новее (вместе с npm), либо распакуйте полный переносной дистрибутив Node.js в `.runtime/node` внутри проекта. В этой папке должны быть `node.exe` и `node_modules/npm/bin/npm-cli.js`.
2. Скачайте репозиторий и распакуйте его целиком в доступную для записи папку, в том числе на внешний SSD или флешку. На каждом компьютере требуется совместимая Windows и Node.js; переносной Node.js можно хранить вместе с проектом.
3. Дважды нажмите `Hanayorina.bat`. При первом запуске нужны интернет и время для установки зависимостей.
4. Откройте http://127.0.0.1:4173 в браузере. Оставьте окно BAT открытым; для остановки нажмите Ctrl+C.

Если порт 4173 занят, закройте использующую его программу и повторите запуск. При ошибке установки проверьте текст в окне и подключение к интернету. Файл не устанавливает Node.js автоматически и не удаляет данные. Пути с пробелами и кириллицей допускаются. Если окно не запускается или появляются непонятные символы, сообщите полный текст ошибки и путь к папке без личных данных.

Для запуска вручную: `npm install`, `npm run build`, `npm start`. Проверка типов: `npm run check`.

## Локальная база PostgreSQL

PostgreSQL устанавливается отдельно и должен быть запущен. Создайте отдельные базу `hanayorina` и пользователя с правами создавать таблицы в этой базе. Пароль задайте самостоятельно. Это можно сделать через pgAdmin. Для надёжности регулярно создавайте резервные копии базы средствами PostgreSQL.

Скопируйте `config/.env.example` в `.env` в папке проекта и укажите реальные `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER` и `PGPASSWORD`. Файл `.env` содержит пароль: не публикуйте и не отправляйте его. Он исключён из Git. При обновлении проекта не заменяйте ваш `.env`.

Запустите `Hanayorina.bat`. При заполненных PGHOST, PGDATABASE и PGUSER приложение проверит соединение и создаст начальные таблицы, сохраняя существующие данные. Повторный запуск не создаёт таблицы заново. Если соединение не удалось, запуск остановится с сообщением в окне: проверьте службу PostgreSQL, настройки, права и пароль. Без настройки подключения стартовая страница запускается без базы.

Созданы таблицы для чатов, сообщений, памяти, агентов и их задач, документов, связей и настроек. Это только структура хранения: интерфейс чата, сохранение данных, поиск, pgvector и автоматическое развитие памяти ещё не реализованы. Сам PostgreSQL и база не устанавливаются и не создаются автоматически.
